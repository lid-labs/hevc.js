# 8.7.3 — Sample Adaptive Offset (SAO)

Spec ref: 8.7.3.1 (general), 8.7.3.2 (edge offset), 8.7.3.3 (band offset)

## Overview

SAO is a post-deblocking filter that applies offsets to samples to reduce quantization artifacts. It operates per CTU, with parameters signalled in the bitstream.

### SAO modes

| sao_type_idx | Mode | Description |
|-------------|------|-------------|
| 0 | Off | No SAO for this CTU/component |
| 1 | Band Offset | Offset per amplitude band |
| 2 | Edge Offset | Offset based on the comparison with the neighbors |

## SAO parameters per CTU (7.3.8.3)

```
sao(rx, ry) {
    // Merge flags: signalled ONCE per CTU (apply to ALL components)
    if (rx > 0)  // not the first CTU of the row
        sao_merge_left_flag                ae(v)
    if (ry > 0 && !sao_merge_left_flag)  // not the first row
        sao_merge_up_flag                  ae(v)

    if (!sao_merge_left_flag && !sao_merge_up_flag) {
        // Per-component parameters
        for (cIdx = 0; cIdx < (ChromaArrayType != 0 ? 3 : 1); cIdx++) {
            if (cIdx == 0 || cIdx == 1)  // luma or Cb
                sao_type_idx[cIdx]         ae(v)  // 0=off, 1=band, 2=edge
            // Note: Cr shares the type of Cb in the spec (sao_type_idx[2] = sao_type_idx[1])

            if (sao_type_idx[cIdx] != 0) {
                for (i = 0; i < 4; i++)
                    sao_offset_abs[cIdx][i]     ae(v)
                if (sao_type_idx[cIdx] == 1) {
                    // Band offset: signs + position
                    for (i = 0; i < 4; i++)
                        sao_offset_sign[cIdx][i]    ae(v)
                    sao_band_position[cIdx]          ae(v)
                } else {
                    // Edge offset: no sign (fixed per category)
                    sao_eo_class[cIdx]               ae(v)
                }
            }
        }
    }
}
```

## 8.7.3.2 — Edge Offset

### EO Classes (directions)

```
Class 0 (Horizontal)  : p-1,0  p0,0  p1,0
Class 1 (Vertical)    : p0,-1  p0,0  p0,1
Class 2 (Diagonal 135): p-1,-1 p0,0  p1,1
Class 3 (Diagonal 45) : p1,-1  p0,0  p-1,1
```

### Categories and offsets

```cpp
// For each sample p(x,y) of the CTU:
int a = ref_sample_1;  // neighboring sample in the EO direction
int b = ref_sample_2;  // opposite neighboring sample
int c = current_sample;

// Categorization
int edgeIdx;
if (c < a && c < b) edgeIdx = 0;      // Valley
else if (c < a || c < b) edgeIdx = 1;  // Concave (partial valley)
else if (c == a && c == b) edgeIdx = 2; // Flat (no offset)
else if (c > a || c > b) edgeIdx = 3;  // Convex (partial peak)
else edgeIdx = 4;                       // Peak

// Offset application
// The offsets for EO are constrained:
// Category 0 (valley): offset > 0
// Category 1 (concave): offset > 0
// Category 2 (flat): offset = 0 (always)
// Category 3 (convex): offset < 0
// Category 4 (peak): offset < 0
const int sao_offset_val[5] = {
    +sao_offset[0],   // valley
    +sao_offset[1],   // concave
    0,                 // flat
    -sao_offset[2],   // convex
    -sao_offset[3]    // peak
};

output_sample = Clip1(current_sample + sao_offset_val[edgeIdx]);
```

## 8.7.3.3 — Band Offset

Divides the amplitude range [0, 2^BitDepth-1] into 32 bands. 4 consecutive bands receive offsets:

```cpp
void apply_band_offset(int16_t* samples, int stride, int width, int height,
                        const int offsets[4], int band_position, int bit_depth) {
    int max_val = (1 << bit_depth) - 1;

    for (int y = 0; y < height; y++) {
        for (int x = 0; x < width; x++) {
            int sample = samples[y*stride + x];
            int band = sample >> (bit_depth - 5);  // 32 bands

            int band_idx = band - band_position;
            if (band_idx >= 0 && band_idx < 4) {
                samples[y*stride + x] = Clip3(0, max_val, sample + offsets[band_idx]);
            }
        }
    }
}
```

## SAO Merge

The `sao_merge_left` and `sao_merge_up` flags are signalled **only once per CTU**, not per component. When a merge is active, the SAO parameters of the 3 components (Y, Cb, Cr) are copied from the left or above CTU respectively.

**Warning**: the availability conditions of the neighboring CTU must be checked:
- `sao_merge_left`: only if the left CTU is in the same slice and the same tile
- `sao_merge_up`: only if the above CTU is in the same slice and the same tile

## Application order

```
1. Deblocking filter on the whole picture
2. SAO on the whole picture (uses the post-deblocking samples)
```

SAO operates on the samples **after** deblocking.

## Known pitfalls

1. **CTU borders**: EO comparisons at CTU borders use the samples of the neighboring CTU (after deblocking, not after the neighbor's SAO)
2. **Cross-slice/tile**: Controlled by `slice_loop_filter_across_slices_enabled_flag`
3. **Chroma sub-sampling**: The chroma CTU size is CtbSizeY/SubWidthC x CtbSizeY/SubHeightC
4. **Merge left/up**: Copies ALL components simultaneously. The merge flags are at CTU level, not at component level
5. **sao_type_idx for Cr**: In the Main profile, the SAO type of Cr is signalled independently of Cb. But in some profiles, they may be linked. Check the spec version.
