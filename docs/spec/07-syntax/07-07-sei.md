# §7.3.7 / Annex D — SEI Messages

Spec ref: §7.3.7 (SEI RBSP syntax), Annex D (SEI message semantics)

## Priority: LOW

SEI (Supplemental Enhancement Information) messages are not needed for decoding. They provide optional metadata.

## decoded_picture_hash (payloadType 132)

Particularly useful for validation:

```
decoded_picture_hash() {
    hash_type    u(8)   // 0=MD5, 1=CRC, 2=checksum
    for(cIdx = 0; cIdx < (ChromaArrayType == 0 ? 1 : 3); cIdx++) {
        if(hash_type == 0)
            picture_md5[cIdx][0..15]    b(8) x16
        else if(hash_type == 1)
            picture_crc[cIdx]            u(16)
        else
            picture_checksum[cIdx]       u(32)
    }
}
```

This SEI makes it possible to verify decoding independently of the libde265 oracle!
